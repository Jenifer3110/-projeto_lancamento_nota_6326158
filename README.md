# Automação de Lançamento de Notas Acadêmicas

Projeto desenvolvido em Python para automatizar o lançamento de notas acadêmicas utilizando PyAutoGUI e arquivos CSV.

## Objetivo

Ler os dados dos alunos, organizar as informações e preparar a automação do lançamento de notas conforme as orientações da atividade.

## Tecnologias

- Python
- PyAutoGUI
- CSV
- Git e GitHub
